# Rossby Financial — CVP & Advisor Tools

This repository holds two related tools:

## 1. `Rossby_CVP_Multi_Office_Model.xlsx` — Multi-Office CVP & Breakeven Model
An internal managerial-accounting **Cost-Volume-Profit** workbook for Rossby Financial. It answers
"how many offices do we need to break even, and how does that breakeven move as we add offices?" and
tracks the contribution of every existing office.

**Tabs**
- **Read Me** — definitions, data sources, and how to use the model.
- **Assumptions & Fixed Costs** — editable annualization factor (default ×2) and every P&L expense
  line with Include?/Recurring? toggles. The paid-off debt (Interest) plus flagged one-time items
  (Suspense, Conference) are pre-set OFF. Also holds the editable pricing-engine tiers.
- **Office Register** — the 18 active offices (preloaded from the 2026 Billing book) with actual
  billed revenue, the engine's list-price for comparison, cost-to-serve, and contribution. Add
  prospects in the blank rows.
- **CVP Dashboard** — total contribution vs. fixed costs, firm net operating income, breakeven
  office count, margin of safety, and a breakeven-shift schedule + chart.
- **New Office Evaluator** — price a prospective office off the tiered engine and see its marginal
  impact on net income and breakeven.

**Key figures (as built):** go-forward annual fixed costs ≈ **$573,937**; 18 offices contributing
≈ **$591,564**/yr → firm net operating income ≈ **+$17,627** (right at breakeven today).

**Reconciliation to the P&L:** on the Assumptions tab set the annualization factor to `1` and toggle
Interest, Suspense, and Conference back to `Y`; total fixed then equals the P&L's **$322,189.06** of
operating expenses — confirming the model faithfully reproduces the statement before normalization.

### Regenerating the workbook
The workbook is generated by a committed script so it stays reviewable and reproducible:

```bash
pip install openpyxl
python3 tools/build_cvp_model.py
```

Source data: Rossby Financial P&L (Jan 1 – Jul 1 2026, cash basis) and the Rossby 2026 Billing book
(tab "2026 Billing"). The per-office pricing engine (base + per-account + per-advisor tiers) is ported
from `index.html` so both tools price offices identically.

## 2. `index.html` — Advisor Profitability Calculator
The advisor-facing sales calculator: it shows a single advisor practice their profit today vs. their
profit on Rossby pricing (the uplift). Open the file in any browser — no build step.
